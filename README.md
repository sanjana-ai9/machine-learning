# Day 31 – Feature Selection for Machine Learning

## 📌 Project Overview
This project focuses on understanding feature selection in machine learning using the Iris dataset. The task involves selecting suitable input features and a target variable for a supervised machine learning problem.

## 🎯 Objective
To understand the basic structure of supervised machine learning and identify input features (X) and a target variable (y).

## 🛠️ Tools and Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## 📂 Dataset
**Iris Dataset**

The Iris dataset contains 150 records of flower measurements belonging to three different species.

## 📊 Selected Input Features (X)
The following four columns were selected as input features:

1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width

## 🎯 Target Variable (y)
**Species**

The target variable represents the type of flower that the model is expected to predict.

The three species are:
- Setosa
- Versicolor
- Virginica

## ⚙️ Implementation Steps
1. Imported the required libraries.
2. Loaded the Iris dataset using Scikit-learn.
3. Converted the dataset into a Pandas DataFrame.
4. Explored the dataset structure.
5. Checked for missing values.
6. Selected four input features.
7. Selected Species as the target variable.
8. Displayed the target classes.
9. Explained the reason for feature and target selection.

## 📈 Results
- Total Records: 150
- Total Columns: 5
- Selected Input Features: 4
- Target Variable: Species
- Target Classes: 3
- Missing Values: 0

## 📚 Learning Outcomes
- Understood the concept of feature selection.
- Learned the difference between input features and target variables.
- Practiced loading datasets using Scikit-learn.
- Learned basic supervised machine learning concepts.
- Understood why the target column should not be included in input features.
